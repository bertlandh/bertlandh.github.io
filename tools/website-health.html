What this can tell you

See whether key information is present in the page’s returned HTML, with suggestions to discuss with your developer.

What needs a separate review?

Page speed, actual mobile usability, image file sizes, full accessibility, backups and security vulnerabilities need additional checks. PHP versions are often hidden; a public header is not proof of the installed version.
